# اف‌گیم درایور - پروژه مستقل اندروید

این پروژه کد HTML فعلی سایت را داخل یک WebView امن و محلی بسته‌بندی می‌کند و فهرست بازی‌ها را به «اف‌گیم درایور» محدود می‌کند. موتور اصلی بازی و تغییرات موجود در `index.html` حفظ شده‌اند.

## ساخت APK

پروژه را در GitHub قرار دهید و از تب Actions، گردش‌کار **Build FGame Driver APK** را اجرا کنید. فایل APK در Artifact با نام `FGameDriver-apk` قرار می‌گیرد.

## نکته درباره امکانات آنلاین

بازی محلی و ذخیره‌سازی مرورگر می‌تواند داخل برنامه اجرا شود. قابلیت‌هایی که به PHP سایت (گزارش باگ، تله‌متری، اعلان‌های سایت) وابسته‌اند در این نسخه بدون سرور خودکار کار نمی‌کنند. قابلیت‌های Supabase/چندنفره نیز به تنظیمات و دسترسی سرویس اصلی وابسته‌اند. این پروژه هنوز APK کامپایل‌شده یا تست‌شده روی دستگاه نیست.
